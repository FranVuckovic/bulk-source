Sample data

A development tool, not part of the app. It fills the same database the app uses with an invented training history so every chart and screen has something real to show.

✓Your real training data is out of reach from here. This writes into a separate database called bulk-demo and switches the app into demo mode. Nothing on this page can read or touch the real log — it is a different database, not a carefully avoided one.
!Everything this writes is fake. Turn demo mode off — here, or from Settings in the app — to get your real data back exactly as it was.
Reading the database…

Loading always clears the demo database first. Sessions are keyed by an auto-incrementing id, so loading twice on top of itself would silently give you every session twice.

Then open the app.

What it creates

Twelve rotations — about seventeen weeks — of the real FOPIP plan, resolved through the same plan engine the Train screen uses, so every session is exactly what the app would have prescribed on that rotation. That deliberately crosses three blocks (Baseline, Accumulation I, Intensification I) so the block comparison has something to compare, and it leaves the last rotation part-finished so the cycle card has a partial state to show.

Also: a daily weigh-in for every day of that stretch climbing about 0.45 kg a week, tape measurements every week, two elbow niggles, a form check, physique entries, two yellow-readiness sessions, one skipped session mid-rotation, and working maxes confirmed at each block boundary.
