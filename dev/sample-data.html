Reading the database…

Loading always clears what is there first. Sessions are keyed by an auto-incrementing id, so loading twice on top of itself would silently give you every session twice.

Then open the app.

What it creates

Twelve rotations — about seventeen weeks — of the real FOPIP plan, resolved through the same plan engine the Train screen uses, so every session is exactly what the app would have prescribed on that rotation. That deliberately crosses three blocks (Baseline, Accumulation I, Intensification I) so the block comparison has something to compare, and it leaves the last rotation part-finished so the cycle card has a partial state to show.

Also: a daily weigh-in for every day of that stretch climbing about 0.45 kg a week, tape measurements every week, two elbow niggles, a form check, physique entries, two yellow-readiness sessions, one skipped session mid-rotation, and working maxes confirmed at each block boundary.
