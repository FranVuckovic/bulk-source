# Archive

## `v1/`

The complete Bulk v1 application exactly as published to GitHub Pages and
installed on the phone in August 2026: 129 passing tests, working Train/Body/
Progress/Plan/Settings, export/import and PWA shell.

It is kept because v2 changes the plan engine, the database schema and the
analytics definitions. If a v2 migration ever destroys data, this is the code
that can still read a v1 export.

Do not edit anything in here. The git tag `v1.0` marks the same state with full
history; this directory exists so the files survive independently of git.

## `Bulk-v1-with-approved-icon.zip`

The v1 source snapshot supplied with the v2 update kit, including the approved
suit-bench icon. Kept as received, unmodified.
